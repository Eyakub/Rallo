## What's new

- **Type times the way you say them.** `rallo remind "Standup notes" --at "fri 9am"` works now,
  as do `5pm`, `tomorrow 17:00`, `oct 20` and `in 2 hours`, in your Mac's time zone. In the
  notes panel, Remind Me → **Custom…** shows when a typed time lands before you set it. Rallo
  refuses vague times ("later", "next fri", a bare "9") instead of guessing.
- **Shortcuts, Siri and Services.** "Add Rallo Note" and "Add Rallo Reminder" are Shortcuts
  actions, and Siri answers "Add a note in Rallo" and "Remind me in Rallo". In any app, select
  text, right-click, and choose **Services → New Rallo Note**. If a save fails, the notes
  panel opens and says why.
- **Rallo now notices Gemini CLI.** When Gemini CLI asks for permission, the pet waves and the
  session shows in "Waiting for you", like Claude Code, Codex and Grok. Run
  `rallo setup hooks --agent gemini` (or Settings → Agents), and
  `rallo setup skill --agent gemini` so Gemini can save notes for you.
- An unreadable agent settings file no longer stops `rallo setup hooks` for the other agents;
  it's skipped with a warning.
