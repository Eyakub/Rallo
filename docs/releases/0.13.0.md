## What's new

- **Folders.** File notes into folders like Work or Home; a note without one is in **Notes**.
  In the notes panel, the folder chip under the title picks what you see (a folder, or All
  Notes), and new notes go into that folder. New Folder… is in the same dropdown. Right-click a
  note → Move to, with Undo.
- **Tags.** Write `#bug`, `#meeting-notes` or `#কাজ` anywhere in a note and it's a tag, tinted
  rust. Nothing to set up: the tag is the text.
- **The Notes window.** The expand button at the top right of the panel, or Notes Window in the
  menu bar menu, opens a full window. The sidebar has your folders, the views All Notes, Due,
  Done and Deleted, and your tags. Notes are grouped by date. The editor saves as you type.
  - Drag a note onto a folder to move it.
  - ⌘N makes a new note, ⇧⌘N a new folder, and ⌘F searches every folder.
  - If an agent or the CLI changes the note you're editing, Rallo asks: Show Theirs or Keep Mine.
  - Rallo shows in the Dock while the window is open.
- **Deleting a folder** asks whether to keep its notes (they move to Notes) or delete them too
  (they wait in Deleted, where you can restore them).
- **Folders and tags from the command line and agents.**
  - New commands: `rallo note "…" --folder Work`, `rallo move ID --folder Work`,
    `rallo folders`, `rallo tags` and `rallo folder create|rename|delete`.
  - `rallo list` takes `--folder Work`, `--tag bug` and `--done`.
  - JSON output gives each note's `folder` and `tags`.
  - The Rallo skill tells agents to use your existing folders and to ask before making one.
- **Export and import keep folders.** JSON and ZIP exports carry your folders, and CSV gains a
  `folder` column. Older exports still import, into Notes.
- **A smaller pet**, with its curled-up poses scaled to match.

Updating moves your notes to a new format (Rallo takes a backup first). Rallo 0.12 can't open
them afterwards, and can't import exports made by 0.13.
