## What's new

- **Rallo now notices Grok.** When xAI's Grok CLI asks for permission, the pet waves and the
  session shows in "Waiting for you", just like Claude Code and Codex; it clears when the turn
  ends or is cancelled. Run `rallo setup hooks --agent grok` (or Settings → Agents), and
  `rallo setup skill --agent grok` so Grok can save notes for you.
- If you already set up Rallo's Claude Code hooks, Grok sessions are picked up through them
  too (Grok runs Claude Code's hooks), so updating is enough.
