## What's new

- **Images on notes.** Paste a screenshot (⌘V) or drop image files into the note field, or drop
  them on a note to add them there. Expanded notes show thumbnails: click one for Quick Look,
  drag it out to Slack, Mail or Finder, or right-click to copy it, show it in Finder or remove
  it (with Undo). Up to 10 images per note, 10 MB each; a bigger screenshot or paste is saved
  as HEIC so it fits. Search still reads text only.
- **Screenshot to a note.** Turn on Settings → General → "Screenshot to a note (⌃⌥⌘S)", press
  ⌃⌥⌘S, select a region, and the notes panel opens with it ready for a few words. Rallo asks
  for Screen Recording access the first time.
- **Images from the command line and agents.** `rallo note "button misaligned" --image shot.png`
  (up to 10 `--image`), `rallo remind … --image`, `rallo attach ID PATH…` and
  `rallo detach ID IMAGE_ID`. JSON output lists each note's `images` with their paths, and the
  Rallo skill tells agents to save their screenshots with the note.
- **Services and Shortcuts take images.** Select an image in Preview, then Services → New Rallo
  Note. Add Rallo Note and Add Rallo Reminder have an optional Images parameter.
- **Export and import with images.** Settings → Data → "Export Archive with Images (ZIP)…", or
  `rallo export --format zip --output notes.zip`; `rallo import --file notes.zip` brings notes
  and images back. JSON and CSV exports still leave images out and say so. `rallo backup`
  copies your images too, and `rallo doctor` checks them.
- **A bold title only when you write one.** A note's first line is a title only when a line
  break follows it (⇧↩ in the panel), or the part before a colon and space is
  ("Bug: the button is misaligned").
  A one-paragraph note is plain text.

Updating moves your notes to a new format (Rallo takes a backup first); Rallo 0.10 can't open
them afterwards.
