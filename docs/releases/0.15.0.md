## What's new

- **Formatting in the Notes window**, with Apple Notes' shortcuts. **⌘B** bold, **⌘I**
  italic, **⇧⌘X** strikethrough and **⌘E** code; **⇧⌘H** heading, **⇧⌘J** subheading and
  **⇧⌘B** body; **⇧⌘7** bulleted and **⇧⌘9** numbered lists, **⇧⌘L** checklists, **⌘'**
  quotes, **⇧⌘M** code blocks, **⌘K** links and **⌘L** dividers.
  - All of them are in the new Format menu and behind the **Aa** button in the editor's
    toolbar, next to a Checklist button.
  - Click a checkbox (or press **⇧⌘U**) to check it. Return continues a list and ends it on an
    empty item; Tab and ⇧Tab indent. ⌘-click a link to open it.
- **Still plain text underneath.** A note is saved as Markdown (`**bold**`, `- [ ] task`), so
  the CLI, agents, search and exports see exactly what you typed. The marks show, dimmed, only
  on the line you're editing; everywhere else, the note reads formatted.
- Note rows in the window and the panel, the pet's bubble and notification previews show the
  text without the marks.
