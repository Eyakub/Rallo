## What's new

- **Automatic backup.** Settings → Data → Back up to: once a day, to iCloud Drive or any folder
  you pick (Dropbox, a NAS, Google Drive for desktop). Rallo keeps this Mac's two newest backups
  there. See [backup and restore](https://github.com/Eyakub/Rallo/blob/master/docs/backup-and-restore.md).
- **Parakeet, a fast English voice engine.** Settings → Voice → Engine → **Parakeet, on this
  Mac** (macOS 14+). Each phrase comes back in about a tenth of a second, where Whisper turbo
  takes about 3 s, with nearly the same accuracy on English.
  - A one-time 464 MB download from Settings → Voice, checked file by file (size and SHA-256)
    and checked again before each launch's first use. Delete it there too.
  - English only, and Words to recognize aren't used yet. Whisper stays for other languages,
    including Bangla.
  - Short phrases such as "Thank you" are typed: Parakeet doesn't invent them from noise, so
    the filter for Whisper's made-up phrases is off for it.
